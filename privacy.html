お金のものさし

プライバシーポリシー

YouTube チャンネル「お金のものさし」の運営者（以下「運営者」）は、運営ツール（以下「本ツール」）で扱う情報について、次のとおり定めます。

1. 本ツールの利用者

本ツールは運営者本人だけが使う運営ツールです。運営者以外の方の Google アカウントやチャンネルの情報は取得しません。

2. 取得する情報

運営者が Google アカウントで許可した次の範囲で、運営者自身のチャンネルの情報を読み取ります。書き込み・変更・削除はしません。

  • YouTube Data API（youtube.readonly）: チャンネルの基本情報、動画の一覧、動画ごとの公開統計（視聴回数など）
  • YouTube Analytics API・YouTube Reporting API（yt-analytics.readonly）: チャンネルのアナリティクスの数値（視聴回数、総再生時間、平均視聴時間、登録者の増減、インプレッション数、インプレッションのクリック率など）

3. 利用目的

取得した情報は、運営者自身のチャンネルの月次目標・週次計画を立てることと、その振り返りにだけ使います。

4. 保存と第三者への提供

  • 取得した情報と認可のトークンは、運営者のパソコンの中に保存します。
  • 計画の案を作るために、集計した数値を AI（Anthropic 社の Claude）に渡すことがあります。
  • 上記のほかに第三者へ提供・販売することはなく、広告に使うこともありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. YouTube API サービス

本ツールは YouTube API サービスを使用しています。あわせて YouTube 利用規約 と Google プライバシーポリシー をご確認ください。

7. 保存期間・削除・アクセスの取り消し

運営者は、保存した情報をいつでも削除できます。本ツールへのアクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、本ツールは情報を取得できなくなります。

8. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル「お金のものさし」までお寄せください。

9. 改定

本ポリシーを改定するときは、このページを更新します。
