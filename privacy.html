お金のものさし

プライバシーポリシー

「お金のものさし」（YouTube・Instagram・TikTok）の運営者（以下「運営者」）は、運営ツール（以下「本ツール」）で扱う情報について、次のとおり定めます。

1. 本ツールの利用者

本ツールは運営者本人だけが使う運営ツールです。運営者以外の方の Google・Instagram・TikTok のアカウントやチャンネルの情報は取得しません。

2. 取得する情報と行う操作

運営者が各サービスで許可した次の範囲で、運営者自身のアカウントの情報を読み取り、運営者自身が作った動画・画像を登録します。ほかの方のアカウントや投稿には触れません。

  • YouTube Data API（youtube）: チャンネルの基本情報、動画の一覧、動画ごとの公開統計（視聴回数など）の読み取り。運営者が作った動画の非公開でのアップロードと、タイトル・説明文・タグの設定。運営者のチャンネルの再生リストの作成と、動画の追加
  • YouTube Analytics API・YouTube Reporting API（yt-analytics.readonly）: チャンネルのアナリティクスの数値（視聴回数、総再生時間、平均視聴時間、登録者の増減、インプレッション数、インプレッションのクリック率など）の読み取り
  • Instagram API（Instagram ログイン）: 運営者のアカウントの基本情報（ID・ユーザー名・アカウントの種類）と、1日の投稿数の上限の読み取り。運営者が作った動画（リール）と画像（カルーセル）の投稿
  • TikTok Login Kit（user.info.basic）: 運営者のアカウントの基本情報（表示名・アイコン）の読み取り
  • TikTok Content Posting API（video.upload）: 運営者が作った動画を、運営者の TikTok アカウントの受信箱（下書き）に送ること。キャプションを付けて投稿する操作は、運営者が TikTok アプリで行います

YouTube の動画の公開は運営者が YouTube Studio で、TikTok の投稿は運営者が TikTok アプリで行います。本ツールが動画や投稿を削除することはありません。

3. 利用目的

取得した情報は、運営者自身のチャンネルの月次目標・週次計画を立てることと、その振り返りにだけ使います。アップロードと投稿は、運営者が作った動画・画像を運営者自身のアカウントに登録するためだけに行います。

4. 保存と第三者への提供

  • 取得した情報と認可のトークンは、運営者のパソコンの中に保存します。サーバーには保存しません。
  • 計画の案を作るために、集計した数値を AI（Anthropic 社の Claude）に渡すことがあります。
  • 上記のほかに第三者へ提供・販売することはなく、広告に使うこともありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. YouTube API サービス

本ツールは YouTube API サービスを使用しています。あわせて YouTube 利用規約 と Google プライバシーポリシー をご確認ください。

7. 保存期間・削除・アクセスの取り消し

運営者は、保存した情報をいつでも削除できます。本ツールへのアクセスの許可は、次の場所からいつでも取り消せます。取り消すと、本ツールは情報の取得も投稿もできなくなります。

  • Google: Google アカウントの「サードパーティ製のアプリとサービス」
  • Instagram: アプリの「設定 → アプリとウェブサイト」
  • TikTok: アプリの「設定とプライバシー」の中にある、連携しているアプリの管理

8. Instagram・TikTok

本ツールは Instagram API と TikTok for Developers のサービスを使用しています。あわせて Instagram 利用規約、TikTok 利用規約、TikTok プライバシーポリシー をご確認ください。

9. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル「お金のものさし」までお寄せください。

10. 改定

本ポリシーを改定するときは、このページを更新します。

English summary

This is an internal tool used only by the operator of the channel "Okane no Monosashi" (お金のものさし). It has a single user, the operator, and is not offered to the public.

  • What it accesses: only the operator's own accounts, within the permissions the operator grants. YouTube: channel statistics, and private upload of the operator's own videos. Instagram: basic account information, and publishing the operator's own Reels and image carousels. TikTok: basic profile information (user.info.basic), and sending the operator's own videos to the operator's TikTok inbox as drafts (video.upload); the operator completes each post in the TikTok app.
  • What it does not do: it does not access any other person's account or content, and it does not delete videos or posts.
  • Storage and sharing: data and access tokens are stored only on the operator's own computer. Nothing is sold, shared with third parties or used for advertising. Aggregated statistics may be passed to an AI assistant (Anthropic's Claude) to draft the operator's posting plan.
  • Revoking access: the operator can delete stored data at any time and revoke access from the Google, Instagram or TikTok account settings.
