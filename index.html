運営ツールについて

このサイトは、チャンネルの運営者が自分のチャンネルの統計（視聴回数・総再生時間・登録者数など）を確認して投稿の計画と振り返りに使い、自分で作った動画・画像を自分の YouTube・Instagram・TikTok のアカウントに登録する運営ツールの案内です。ツールは運営者本人のみが使い、一般には提供していません。

ツールは YouTube API サービス、Instagram API、TikTok for Developers のサービスを使用し、運営者が各サービスで許可した範囲で、運営者自身のアカウントだけを操作します。比較の参考に、同じ分野のチャンネルの一般に公開されている統計（登録者数など）を読むことがあります。

This site describes an internal tool used only by the channel's operator. It reads the operator's own channel statistics and uploads the operator's own videos to the operator's own YouTube, Instagram and TikTok accounts. It also reads publicly available statistics of a few comparable channels. It is not offered to the public.
