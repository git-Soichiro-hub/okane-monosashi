お金のものさし

働く人のお金を、データで見せる YouTube チャンネルです。

年収・ボーナス・転職・貯金・年金・老後資金について、国や公的機関の統計（国税庁・厚生労働省・総務省など）をもとに、「自分は平均より上？下？」が分かる動画を公開しています。

YouTube チャンネル「お金のものさし」

運営ツールについて

このサイトは、チャンネルの運営者が自分のチャンネルの統計（視聴回数・総再生時間・登録者数など）を確認し、投稿の計画と振り返りに使う運営ツールの案内です。ツールは運営者本人のみが使い、一般には提供していません。

ツールは YouTube API サービスを使用し、運営者が Google アカウントで許可した範囲で、運営者自身のチャンネルの情報だけを読み取ります。
