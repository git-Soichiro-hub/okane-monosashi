お金のものさし

働く人のお金を、データで見せるチャンネルです。

年収・ボーナス・転職・貯金・年金・老後資金について、国や公的機関の統計（国税庁・厚生労働省・総務省など）をもとに、「自分は平均より上？下？」が分かる動画を公開しています。

YouTube チャンネル「お金のものさし」　Instagram @okane_monosashi

運営ツールについて

このサイトは、チャンネルの運営者が自分のチャンネルの統計（視聴回数・総再生時間・登録者数など）を確認して投稿の計画と振り返りに使い、自分で作った動画・画像を自分の YouTube・Instagram・TikTok のアカウントに登録する運営ツールの案内です。ツールは運営者本人のみが使い、一般には提供していません。

ツールは YouTube API サービス、Instagram API、TikTok for Developers のサービスを使用し、運営者が各サービスで許可した範囲で、運営者自身のアカウントだけを扱います。

This site describes an internal tool used only by the channel's operator. It reads the operator's own channel statistics and uploads the operator's own videos to the operator's own YouTube, Instagram and TikTok accounts. It is not offered to the public.
